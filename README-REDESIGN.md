# HYBRID — Cinematic redesign

Пакет содержит переработанные исходники интерфейса сайта конгломерата «Гибрид».

## Установка

1. Сделайте резервную копию текущей папки `src` и `index.html`.
2. Замените соответствующие файлы содержимым архива.
3. Сохраните существующую папку `public/img` — изображения не включены в архив.
4. Установите зависимости и запустите проект:

```bash
npm install
npm run dev
npm run build
```

## Важно по изображениям

Пакет использует существующие изображения из `public/img`. Проверьте наличие файлов:
- `home-hero.jpg`
- `academy-hero.jpg`
- `logo_hybrid.svg`
- `molot-mini.png`, `molot-hero.jpg`, `molot-g1.jpg` ... `molot-g4.jpg`
- `atom-Si.png`, `atom-g2.jpg` ... `atom-g5.jpg`
- `rusalka.jpg`, `shchuka.jpg`, `razryad.jpg`, `manticora.png`
- `academy-dota.jpg`, `academy-cs2.jpg`, `academy-sc2.jpg`, `academy-valorant.jpg`, `academy-fc.jpg`

Если фактические имена отличаются, исправьте пути в `src/data.js` и `src/pages/Academy.jsx`.

## Что переработано

- Кинематографическая главная страница.
- Единая дизайн-система: графит, холодное серебро, фирменный фиолетовый.
- Анимации появления блоков при прокрутке через IntersectionObserver.
- Hover-анимации карточек, изображений и ссылок.
- Каталог с фильтрацией по категориям.
- Продуктовая страница с интерактивным наклоном изображения от движения указателя.
- Адаптивная мобильная навигация.
- Страницы технологий, проектов, компании, документации и Academy.
- Уважение `prefers-reduced-motion`.
- Удалены случайные ссылки на сторонние проекты из контента Гибрид.

## Ограничения текущей версии

- Интерактивный наклон изображения — это визуальный эффект, не настоящая 3D-модель.
- Авторизация кабинета, формы заявок, видео и серверные API требуют отдельной backend-интеграции.
- Технические параметры продуктов намеренно не выдумываются: публичные характеристики нужно сверить с утверждённой инженерной документацией.
- Перед production-деплоем проверьте все пути к изображениям, доступность, SEO, сборку и маршрутизацию хостинга.
