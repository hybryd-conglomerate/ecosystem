## Деплой
1. Залейте содержимое папки в репозиторий GitHub (через веб-интерфейс: Add file → Upload files).
2. vercel.com → Add New Project → выберите репозиторий. Framework: Vite (определится сам), Build `npm run build`, Output `dist`.
3. Settings → Domains → добавьте конгломерат-гибрид.рф и пропишите у регистратора DNS-записи, которые покажет Vercel.
Изображения лежат в public/img (нарезаны из макетов); замените файлы на финальные с теми же именами.
